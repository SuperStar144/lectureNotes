///////////////////////////

Making claims about sequences.

Suppose "seq" is our sequence

k is the position, seq(k) is the value.

∀ (lower until upper)(k => some statement about seq(k) )
    (does NOT include upper)


∀ (0 until seq.size)(k => seq(k) == 0 )
    
    --> what does this say?
        All elements in the sequence are 0.


∀ (0 until seq.size)(k => k > 2 => seq(k) == 0 )
    
    --> what does this say?
        All positions after 2 will be changed to 0.


Similarly, can use ∃

∃ (0 until seq.size)(k => seq(k) == 0 )

    --> what does this say?
        There exists a position that has been changed to 0.
